
# Accord Benchmark

An NLP/LLM benchmark suite for **Smart Legal Contract (SLC)** tasks, built from the
open-source [Accord Project](https://templates.accordproject.org) template library.

This project is part of an MSc dissertation (UCL, MSIN0114) in collaboration with
Docusign / the Accord Project.

## What it does

It measures how well language models perform legal-specific contract tasks. The
benchmark covers five tasks derived from Accord Project templates:

1. **Clause classification** — identify the contract type from clause text
2. **Variable extraction** — pull structured variables (amounts, dates, parties) from prose
3. **Model generation** — generate the Concerto data model for a clause
4. **Logic synthesis** — generate the executable contract logic
5. **FSM generation** — generate the contract's state machine (lifecycle)
